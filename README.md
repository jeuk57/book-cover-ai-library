# 작가의 선택

도서 정보를 등록하고 다른 사용자의 도서를 둘러볼 수 있는 웹 서비스입니다.

제목, 저자, 장르, 언어와 내용을 입력해 도서를 등록할 수 있습니다. 필요한 경우 외부 AI 이미지 생성 API를 이용해 도서 표지도 만들 수 있습니다.

## 제작 목적

텍스트 정보만으로는 도서의 장르와 분위기를 직관적으로 전달하기 어렵다고 생각했습니다.

사용자가 도서 내용을 직접 등록하고, AI가 생성한 표지를 함께 저장할 수 있는 서비스를 만들고자 했습니다.

## 주요 기능

- 회원가입, 로그인, 로그아웃
- 도서 등록, 조회, 수정, 삭제
- 도서 검색
- 좋아요, 찜하기
- 댓글 작성과 삭제
- 내가 등록한 도서와 찜한 도서 조회
- AI 도서 표지 생성 및 저장

AI 표지 생성에는 Stability AI API 키가 필요합니다. API 키가 없어도 표지를 제외한 도서 정보는 정상적으로 등록할 수 있습니다.

## 담당한 부분

이 프로젝트는 팀 프로젝트이며, 저는 Spring Boot 기반 백엔드 개발을 담당했습니다.

- 도서 요청·응답 DTO 작성
- 도서 CRUD 서비스 로직 구현
- 좋아요 토글, 개수 및 사용자 상태 조회 구현
- 찜하기 토글, 개수 및 내 찜 목록 구현
- 댓글 작성, 조회, 수정, 삭제 구현
- 댓글 작성자 권한 확인 구현
- AI 이미지 생성 결과를 도서 표지 정보에 저장하는 흐름 구현

## 프론트엔드 수정

백엔드 개발 후 프론트엔드 디자인도 직접 변경해보고 싶어 기존 화면을 일부 수정했습니다.

- 화면 구성, 폰트와 색상 수정
- 반응형 레이아웃 적용
- 버튼과 아이콘에 간단한 동작 효과 추가

## 기술

- Frontend: React, Vite, Axios, Material UI
- Backend: Java 17, Spring Boot, Spring Data JPA
- Database: H2
- AI Image API: Stability AI

## 실행 방법

### 준비 사항

- Java 17
- Node.js

### 백엔드 실행

```powershell
cd backend
./gradlew.bat bootRun
```

백엔드는 `http://localhost:8080/api`에서 실행됩니다.

### 프론트엔드 실행

새 터미널에서 실행합니다.

```powershell
cd frontend
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5174`로 접속합니다.

## 참고 사항

- AI 표지를 사용하지 않을 때는 도서 등록 화면에서 `AI 표지 사용`을 선택하지 않으면 됩니다.
- H2 메모리 데이터베이스를 사용하므로 백엔드 서버를 다시 실행하면 저장된 데이터가 초기화됩니다.
- API 키는 코드에 저장하지 않고 표지 생성 요청에만 사용합니다.
